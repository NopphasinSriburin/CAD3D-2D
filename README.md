# MorphCAD — เว็บแปลงไฟล์ CAD 3D / 2D

เว็บแอปแปลงไฟล์ CAD ที่ทำงานบนเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์

## ความสามารถ

| โหมด | นำเข้า | ส่งออก |
| --- | --- | --- |
| 3D → 3D | STEP, IGES, BREP, SLDPRT*, STL, OBJ(+MTL), PLY, GLB/glTF, FBX, 3MF, DAE, AMF, 3DS, VRML, OFF | STL, OBJ(+MTL), PLY, GLB, glTF, 3MF, USDZ |
| 3D → 2D แบบงาน | โมเดล 3D ใดก็ได้ข้างต้น | DXF (R12, 1:1), PDF, SVG (สเกลจริง), PNG |
| 2D → 2D | DXF, SVG | DXF, SVG, PDF, PNG |
| 2D → 3D (Extrude) | DXF, SVG | STL, 3MF, OBJ, GLB |
| 3D → BOM | โมเดล 3D ใดก็ได้ข้างต้น | Excel (.xlsx) ชีต BOM + ชีต CBD |

- BOM: รวมชิ้นส่วนที่รูปทรงเหมือนกันเป็นรายการเดียวพร้อมจำนวน วัดขนาดกรอบ พื้นที่ผิว พื้นที่ฉาย 3 แกน และปริมาตร (ชิ้นทึบ) เลือกวัสดุ/ความหนาแน่น/ความหนา/ราคาได้ ช่องสีเหลืองในไฟล์แก้ได้ สูตรน้ำหนักและค่าวัสดุคำนวณใหม่อัตโนมัติ ส่วนชีต CBD สรุปต้นทุนต่อชุด (วัสดุ เศษ ขึ้นรูป ทำสี ขนส่ง โสหุ้ย กำไร) โดยดึงค่าจากชีต BOM

- แบบงาน 2D: ภาพฉายด้านหน้า/บน/ข้าง/ไอโซเมตริก ระบบมุมที่ 1 หรือ 3 เส้นซ่อนแบบเส้นประ ขนาดรวม กรอบชื่อแบบ และเลือกมาตราส่วนอัตโนมัติตามกระดาษ A4–A0
- ตัวดู 3D: โหมดสีจริง/ดินปั้น/โครงลวด/เอ็กซเรย์ เส้นขอบ ตัดหน้าตัด มุมมองออร์โธกราฟิก ซ่อน/แสดงชิ้นส่วน
- ปรับหน่วย (mm, cm, m, in, ft) และแกนตั้ง (Z-up / Y-up) ตอนส่งออก
- ธีมสว่าง/มืด รองรับมือถือ

## เริ่มใช้งาน

**แบบง่ายที่สุด (Windows):** ดับเบิลคลิก `MorphCAD.bat` ระบบจะติดตั้งแพ็กเกจ (ครั้งแรก) สร้างเว็บใหม่ถ้าโค้ดเปลี่ยน เปิดเซิร์ฟเวอร์ที่ http://localhost:4173 แล้วเปิด Chrome ให้ (ถ้าไม่มี Chrome จะใช้ Edge) หน้าต่างดำที่เปิดขึ้นคือเซิร์ฟเวอร์ ปิดเมื่อเลิกใช้

**ติดตั้งเป็นแอป:** กดปุ่ม "ติดตั้งแอป" มุมขวาบนของเว็บ (หรือเมนูเบราว์เซอร์ → ติดตั้ง MorphCAD) จะได้ไอคอนบนเดสก์ท็อป/เมนู Start เปิดเป็นหน้าต่างของตัวเอง และใช้งานได้แม้ไม่ได้เปิดเซิร์ฟเวอร์หรือไม่มีอินเทอร์เน็ต เพราะ service worker เก็บไฟล์ทั้งหมดไว้ในเครื่อง

**โปรแกรม Windows (.exe):** `npm run dist:win` จะได้ตัวติดตั้ง `release/MorphCAD-Setup-<version>.exe` (Electron) ติดตั้งรายผู้ใช้ ไม่ต้องใช้สิทธิ์แอดมิน มีทางลัดบนเดสก์ท็อป/เมนู Start ทำงานออฟไลน์ได้ทั้งหมด และเปิดไฟล์ CAD ผ่าน "Open with" ได้ ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล เครื่องอื่นที่ได้รับไฟล์ผ่านเน็ตจะเห็นคำเตือน SmartScreen (กด More info → Run anyway) ถ้าจะแจกจ่ายในบริษัทควรขอใบรับรอง code signing ส่วน `npm run desktop` ใช้เปิดทดสอบแบบไม่ต้องสร้างตัวติดตั้ง

```bash
npm install      # ติดตั้งแพ็กเกจ และคัดลอกไฟล์ WASM ไปที่ public/vendor
npm run dev      # เปิดเซิร์ฟเวอร์พัฒนา (http://localhost:5173)
npm run build    # สร้างเว็บสำหรับใช้งานจริงในโฟลเดอร์ dist/
npm run preview  # ทดสอบไฟล์ใน dist/
npm run app      # build ใหม่ + เปิดเซิร์ฟเวอร์ + เปิดเบราว์เซอร์ (แบบเดียวกับ MorphCAD.bat)
```

โฟลเดอร์ `dist/` เป็นเว็บแบบ static ทั้งหมด นำไปวางบนโฮสต์ใดก็ได้ (GitHub Pages, Netlify, NAS) และใช้ path แบบ relative จึงวางใน sub-folder ได้

## โครงสร้างโค้ด

```
src/
  main.js            ตัวควบคุมหน้าเว็บ (สถานะ, แผง, การแปลง)
  core/              รายการรูปแบบไฟล์ และหน่วย
  io/                อ่าน/เขียนไฟล์ (load3d, load2d, export3d, export2d, occt)
  cad/               โมเดลแบบ 2D, ภาพฉาย 3D→2D, จัดหน้ากระดาษ, extrude, ไฟล์ตัวอย่าง
  three/             ตัวดู 3D, แกนอ้างอิง, ฉากหน้าแรก
  ui/                ตัวดู 2D, ไอคอน, การแจ้งเตือน
  styles/main.css    ดีไซน์ทั้งหมด (โทเคนสีสำหรับธีมสว่าง/มืด)
public/workers/      Web Worker สำหรับอ่าน STEP/IGES ด้วย OpenCascade
public/sw.js         Service worker สำหรับใช้งานออฟไลน์ (รายชื่อไฟล์ถูกเติมตอน build)
electron/            ตัวโปรแกรม Windows (Electron) — เสิร์ฟ dist/ ผ่าน app:// และรับไฟล์จาก Explorer
build/               ไอคอนสำหรับตัวติดตั้ง
scripts/             คัดลอกไฟล์ WASM หลังติดตั้ง และตัวเปิดแอปของ MorphCAD.bat
```

## ข้อจำกัด

- \*SLDPRT (SolidWorks 2015 ขึ้นไป) อ่านได้เฉพาะ mesh แสดงผลที่ SolidWorks ฝังไว้ในไฟล์ (`Contents/DisplayLists`) ไม่ใช่พื้นผิว B-Rep จริง ความละเอียดจึงเท่ากับค่าคุณภาพภาพตอนบันทึก ไฟล์ SLDPRT รุ่นเก่า (รูปแบบ OLE) และ SLDASM ยังไม่รองรับ
- ไม่รองรับ DWG (รูปแบบปิด) — บันทึกเป็น DXF ก่อน
- ส่งออก STEP/IGES ไม่ได้ เพราะต้องใช้ข้อมูลพื้นผิว B-Rep ซึ่ง mesh ไม่มี
- การแยกเส้นซ่อนคำนวณจาก depth buffer ความละเอียด 2048 px ต่อมุมมอง อาจมีจุดคลาดเล็กน้อยตรงขอบที่ชิดกันมาก
